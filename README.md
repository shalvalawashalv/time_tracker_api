# Time Tracker API

Backend-сервис для учета времени по активностям.

## MVP

Пользователь может:
- зарегистрироваться
- залогиниться
- создать activity, например Algorithms / Backend / Reading
- запустить time session по activity
- остановить активную session
- добавить comment к завершенной session
- посмотреть список своих sessions
- отфильтровать sessions по activity и датам
- посмотреть суммарное время по activity

## Business rules

- У пользователя может быть только одна активная session.
- Пользователь видит только свои данные.
- Нельзя остановить чужую session.
- Нельзя остановить уже завершенную session.
- В статистику попадают только завершенные sessions.
